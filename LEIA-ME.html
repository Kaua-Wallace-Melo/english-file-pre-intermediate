Guia de uso

English File Pre-Intermediate

Leia o livro, navegue pelas páginas e ouça os áudios diretamente no navegador.

Comece aqui

Como usar

  1. Descompacte a pasta em qualquer lugar do computador.
  2. Confira se os MP3 estão dentro da pasta audio.
  3. Abra index.html com um duplo clique.
  4. Clique nos ícones de áudio presentes nas páginas.
Navegação

Recursos

  • Use as setas ou o campo de página para navegar.
  • Ajuste o zoom conforme o tamanho da janela.
  • Use Destacar áudios para localizar os botões.
  • Pressione espaço para pausar ou retomar.
  • Use as setas esquerda e direita para avançar 5 segundos.
  • Altere a velocidade e repita uma faixa quando quiser.
Novo livro

Adicionar outro PDF

O índice usa imagens WebP para funcionar por duplo clique, sem servidor ou internet. Para preparar outro livro:

  1. Faça uma cópia de segurança da pasta pages.
  2. Instale o ImageMagick no Windows e habilite a opção de adicioná-lo ao PATH.
  3. Crie uma pasta vazia chamada pages-novo.
  4. Abra o PowerShell na pasta do índice e execute o comando abaixo, substituindo o caminho do PDF:
magick -density 150 -scene 1 "C:\caminho\outro-livro.pdf" -quality 85 "pages-novo\p%03d.webp"
  1. Confira se os arquivos estão nomeados como p001.webp, p002.webp, p003.webp...
  2. Substitua a pasta antiga: renomeie pages e depois renomeie pages-novo para pages.
  3. Abra o index.html. O número de páginas será detectado automaticamente.
Atenção: se o primeiro arquivo aparecer como p000.webp, renomeie-o para p001.webp e ajuste a numeração dos arquivos seguintes.
Áudio

Adicionar MP3

Coloque os arquivos na pasta audio. Se o padrão dos nomes for diferente, altere no início do bloco <script> do index.html:

  • AUDIO_DIR: pasta dos áudios.
  • AUDIO_PREFIX: texto antes do número da faixa.
  • AUDIO_EXT: extensão dos arquivos.

Se uma faixa não tocar, o player exibirá o nome exato do arquivo que procurou.

Personalização

Botões clicáveis

Os botões de áudio ficam na constante HOTSPOTS. Para outro livro, eles precisam ser recriados com:

  • número da página;
  • número da faixa;
  • posição e tamanho do ícone em porcentagem.

Sem novos hotspots, o livro será exibido normalmente, mas não terá ícones de áudio clicáveis. Para fazer esse trabalho, use uma IA como o Claude Code

Organização

Estrutura da pasta

  ...

  nome-do-arquivo.mp3

O PDF original pode ficar na pasta como fonte da conversão, mas não é necessário para usar o índice depois que as páginas WebP foram geradas.
